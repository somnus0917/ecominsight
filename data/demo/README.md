# Synthetic demo data

Only records generated by `scripts/generate_demo_data.py` may be placed here. Every generated
record carries `synthetic=true` and passes privacy, metric-identity, cross-domain reconciliation
and controlled-scenario verification before it is written.

`generated/` contains a deterministic public dataset with 140 daily observations, four fictional
shops and ten labeled anomaly scenarios. It uses bounded rate medians from the local sanitized
warehouse when available, but never copies real rows, amounts, names or entity identifiers.

Regenerate it with:

```bash
uv run ecom-generate-demo-data
```

Use `--reference-database` to select a local sanitized DuckDB or point it to a nonexistent path to
use safe built-in defaults. Real and synthetic evaluation results must always be reported
separately.

No real, scaled, shifted or merely pseudonymized customer orders belong in this directory.
